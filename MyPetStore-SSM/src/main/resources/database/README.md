# 工程内 SQL 副本

本目录的 `01-schema.sql`、`02-schema-with-demo.sql` 是仓库根目录 `database/` 的**只读副本**，用于与课程视频中的工程结构保持一致，方便在 IDE 内直接查看/执行。

- 唯一维护来源：仓库根目录 [`database/`](../../../../../database/)；修改 SQL 时请改根目录文件，再同步本目录。
- 应用启动**不会**自动执行本目录脚本（`spring.sql.init.mode=never`），数据库仍需按根目录 [数据库说明](../../../../../database/README.md) 手工初始化。
- 二选一：`01` 仅建结构，`02` 建结构并写入演示数据；不要按编号连续执行。
