状态说明：

- **已实现**：代码路径存在并可在演示数据上运行；
- **自动验证**：有 JUnit/Mockito/MockMvc 用例；
- **手工验证**：已在 8080/8081 实际运行的应用上按操作步骤验证；
- **代码审查**：边界/并发场景未单独构造故障注入，由条件更新、行锁、事务与单测覆盖设计意图。

## 3. 展示与通用要求

| 要求 | 实现 |
| --- | --- |
| 服务端渲染、Spring MVC + Thymeleaf | 两端均使用 Controller + Thymeleaf；无前后端分离/REST 前端 |
| 数据访问 | MyBatis-Plus `BaseMapper` + 条件构造器 + 少量注解/XML SQL |
| 金额/时间格式 | `MoneyFormatter`、`DateTimeFormatterBean` |
| 分页 | `PageParams`/`PageLinks`/`PageResult`；筛选条件保留 |
| 错误页 | 400/403/404/409/500；不输出堆栈 |
| CSRF | 会话 Token；写请求校验；smoke 验证 403 |
| 双端独立 | 端口 8080/8081；Cookie 名不同；互不影响 |
| 数据初始化 | `database/02-schema-with-demo.sql`；应用不自动清库 |
| 文档 | 设计说明、本清单、验证记录、视频对照、提交记录 |

## 4. 验收准则覆盖概览

PRD 第 11 章 AC-01—AC-34 的逐条操作与证据见 [验证记录](验证记录.md)。汇总：

- **自动验证**：AC-05（AuthService）、AC-25/26（Category/Product 单测）、AC-27（版本冲突单测）、AC-29（发货单测）、AC-33/34 的密码/状态规则；共 67 个测试（用户端 43 + 管理端 24）。
- **手工验证**：AC-01—AC-04、AC-06—AC-13、AC-14、AC-19—AC-22、AC-24、AC-25、AC-27、AC-29、AC-30、AC-32、AC-33、AC-34 的代表性路径。
- **覆盖边界**：AC-16（事务注入）、AC-17（同账号并发）、AC-23（取消后注入异常）、AC-28（两工程同时购物/补货）未做真实故障注入/并发压测；对应设计为行锁、唯一约束、条件更新和事务回滚，已在设计说明中说明。验收时如需逐条构造，可按验证记录中的“待构造”一节操作。
