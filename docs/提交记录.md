# 提交记录

本文件记录实验一的检查点提交。每次提交前先在对话中列出“提交清单”，确认纳入/排除文件、验证命令、数据/安全影响与回滚方式；提交后回填哈希与推送结果。

仓库：`https://github.com/zhanchongen/MyPetStore.git`，分支 `main`。

## 提交清单模板

每个检查点记录：

1. **提交信息**：类型 + 范围 + 说明；
2. **纳入文件**：精确路径/模式；
3. **排除文件**：课程原始视频/PDF/DOC/ZIP、`.tools/`、`.tmp-docs/`、`target/`、本地数据库；
4. **验证**：构建/测试/手工冒烟；
5. **安全/数据影响**：是否改表、是否暴露演示接口、是否清库；
6. **回滚**：`git revert <hash>`；
7. **推送**：`git push origin main` 结果。
