# 提交记录

本文件记录实验一的检查点提交。每次提交前先在对话中列出“提交清单”，确认纳入/排除文件、验证命令、数据/安全影响与回滚方式；提交后回填哈希与推送结果。

仓库：`https://github.com/zhanchongen/MyPetStore.git`，分支 `main`。

## 提交清单模板

每个检查点记录：

1. **提交信息**：类型 + 范围 + 说明；
2. **纳入文件**：精确路径/模式；
3. **排除文件**：课程原始视频/PDF/DOC/ZIP、`.tools/`、`.tmp-docs/`、`target/`、本地数据库；
4. **验证**：构建/测试/手工冒烟；
5. **安全/数据影响**：是否改表、是否暴露演示接口、是否清库；
6. **回滚**：`git revert <hash>`；
7. **推送**：`git push origin main` 结果。

## 检查点 10—12：页面观感修复

起因：交付后发现页面「没有设计感、像是没有图片」。排查结论不是审美问题，而是**渲染层断链**：

1. `jpetstore.css` 按 Sora 字体度量设计，但工程里没有任何 `@font-face`，Windows 回退 Segoe UI，字号阶梯与字重全部失效；
2. 13 个模板缺 `<body>` 页面级 class 与 `.mpa-shell` 外层，设计稿里大量后代选择器选不中元素；
3. 40 个演示 SKU 的封面是「大字 + SKU」文字占位卡，在商品网格里等同于没有图片；
4. 登录页/入口页把 100×100 的 `dog1.gif` 当 `background-image` 用，被平铺成满屏巨图；
5. 订单列表没有封面字段，卡片缩略图全是放大的 logo。

对应修复见 `docs/视觉验收.md` 第 2 节；验收方式为 `scripts/capture-pages.mjs` 无头浏览器逐页整页截图（18 页）。
